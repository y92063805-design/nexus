# ✦ NEXUS

**مرکز فرماندهی نسل بعدی برای AI Agents**

🎯 دمو آنلاین: https://y92063805-design.github.io/nexus/

## 🏭 داستان

فرض کنید یک شرکت دارید که کارمندانش آدم نیستند — **ربات‌های هوش مصنوعی‌اند.**

یکی فقط تحقیق بلد است، یکی فقط کد می‌نویسد، یکی تصویر می‌خواند و یکی هم مراقب امنیت است. یک مدیر هم دارد که به همه دستور می‌دهد.

**NEXUS اتاق فرماندهیِ همین کارخانه است.**

جایی که می‌توانید نبض سیستم را ببینید، تیم را تماشا کنید و به کارخانه دستور بدهید و مراحل اجرای آن را زنده تماشا کنید: مدیر مأموریت را تحلیل می‌کند، ایجنت متخصص بیدار می‌شود و می‌درخشد، کارش را انجام می‌دهد و گزارش نهایی را تحویل می‌دهد.

> ⚠️ این پروژه یک **رابط مفهومی (Concept UI)** است — ایجنت‌ها شبیه‌سازی شده‌اند. اما ایده‌ی پشت آن جدی است: آینده‌ای که به جای چت با *یک* هوش مصنوعی، یک **تیم** از آن‌ها را هماهنگ می‌کنیم.

## ✨ امکانات

- 🎛 **اتاق فرماندهی** — یک جمله فارسی بنویسید و ایجنت مناسب بیدار می‌شود
- ✨ **کارت‌های زنده** — ایجنتی که مشغول کار است می‌درخشد
- 🌌 **پس‌زمینه‌ی نفس‌کش** — شناور، نفس‌کش و با شعاع نور گذرا
- ⚛️ **شبکه‌ی ذرات تعاملی** — ذرات از موس فرار می‌کنند
- 🖱 **کرسر سفارشی** با حلقه‌ی دنبال‌کننده
- 📡 **فید فعالیت لحظه‌ای** کارخانه
- ⌨️ **پالت فرمان** با Ctrl + K
- 🏃 **بهینه‌سازی خودکار** برای سیستم‌های ضعیف
- 📱 کاملاً **ریسپانسیو**

## 🤖 تیم کارخانه

| ایجنت | تخصص | کلیدواژه‌ها |
|---|---|---|
| 🧠 Orchestrator | مغز هماهنگ‌کننده و توزیع‌کننده‌ی مأموریت | همه‌چیز از اینجا شروع می‌شود |
| 🔍 Research | تحقیق و اعتبارسنجی منابع | تحقیق، قیمت، بازار، خبر |
| 💻 Code | تحلیل، تولید و تست کد | کد، باگ، تست، برنامه |
| 👁 Vision | درک تصویر و اسکن اسناد | عکس، تصویر، سند |
| 📊 Analyst | تبدیل داده به گزارش | گزارش، تحلیل، آمار |
| 🛡 Security | پایش رخدادها و ریسک | امنیت، هک، ترافیک |

## 🗂 ساختار پروژه

- `index.html` — صفحه‌ی اصلی: ویترین، داشبورد، شبکه‌ی ایجنت‌ها
- `console.html` — اتاق فرماندهی: دستور بده، کارخانه را ببین
- `style.css` — تمام استایل‌ها و افکت‌های زنده
- `script.js` — مغز سایت: ذرات، موتور مأموریت، ساعت، فید
- `background.png` — پس‌زمینه‌ی زنده‌ی سایت
